# LAB-02: Device Driver & File System

## Giới thiệu
Bài thực hành tập trung vào phát triển Linux Kernel Module, xây dựng Character Device Driver và tìm hiểu cơ chế quản lý File System trong hệ thống Linux nhúng.

## Nội dung thực hiện
- Xây dựng và quản lý Kernel Module.
- Phát triển Character Device Driver.
- Giao tiếp giữa Kernel Space và User Space.
- Sử dụng procfs và sysfs để quản lý, hiển thị thông tin.
- Tìm hiểu MTD, NAND Flash và JFFS2.
- Tích hợp Kernel Module vào quá trình khởi động hệ thống.

## Công nghệ sử dụng
- C Programming
- Linux Kernel Module
- Character Device
- procfs / sysfs
- MTD / JFFS2
- BusyBox
- QEMU (ARMv7)

## Mục tiêu
Nắm được quy trình phát triển Device Driver và cách Linux quản lý thiết bị, bộ nhớ Flash và File System.
